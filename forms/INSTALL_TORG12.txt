ТОРГ-12: КГ → МАССАБРУТТО ИЗ КОЛИЧЕСТВА; ШТ → ШТАТНЫЙ ВЕС

ПОДГОТОВЛЕНО ПО ВАШЕМУ МОДУЛЮ МЕНЕДЖЕРА РАСХОДНОЙ НАКЛАДНОЙ
Файлы:
1. torg12_manager_fixed.bsl — полный присланный модуль с одной вставкой.
2. torg12_insert_block.bsl — только вставляемый участок.
3. torg12_manager.diff — точная разница с присланным модулем.
4. torg12_supported.mxl — макет с исходными работающими параметрами;
   уточнены только подписи веса, количества в кг/шт и общего веса.

КУДА ДОБАВЛЕН КОД
Конфигуратор → Документы → РасходнаяНакладная → Модуль менеджера.
Процедура Печать. Ветка:
    ВозможныеВарианты = Обработки.ПечатьТОРГ12.МатрицаВозможныхВариантов();

Сразу после этих двух строк (11590–11591 в вашем файле):
    ДанныеОбъектовПечати = ДанныеДокументовРегУчет(МассивОбъектов,
        СтрокаТаблицы.ИспользоватьФаксимиле, Истина, Ошибки);

Вставка выполнена до вызова:
    Обработки.ПечатьТОРГ12.СформироватьПФ(...);

КАК ПРИМЕНИТЬ
Сохраните копию текущего модуля и макета. Вставьте блок из
torg12_insert_block.bsl в указанное место. Полный исправленный модуль
предоставлен для сравнения и удобства, а не для замены более новой
редакции с другими изменениями. Для типовой конфигурации изменение
обычно оформляется расширением; сгенерированного .cfe в комплекте нет.
В Конфигураторе проверьте модуль и примените изменение к базе.
В разделе макетов печатных форм загрузите torg12_supported.mxl.

ЛОГИКА
Для запасов с печатным ОКЕИ 166:
    МассаБрутто = Количество × КоэффициентЕдиницыИзмерения.
Для прямых кг коэффициент 1: 4 × 1 = 4 кг.
Для ввода в упаковках с печатью в кг: 10 × 0,4 = 4 кг.
Для шт и других единиц сохраняется стандартная МассаБрутто из поля Вес.
Услуги и подарочные сертификаты не получают массу из количества.
Количество, цены, скидки, НДС и финансовые суммы не пересчитываются.
Изменение находится только в ветке ТОРГ-12; общий запрос не изменён.

Если в документе есть кг и для прочих запасов заполнены массы,
печатное поле шапки Вес также получает сумму МассаБрутто по запасам.
Услуги и подарочные сертификаты в эту новую сумму не включаются.
Если у непустой строки запаса вес равен 0, полный вес не
подтверждён. В этом случае Вес шапки не заменяется частичной суммой;
заполните вес штучного товара перед проверкой полного веса накладной.
Стандартное суммирование таблицы может показывать известную часть веса.
Нетто и тара отдельно не рассчитываются: используется запрошенное вами
поле МассаБрутто и штатный Вес для штучных товаров.

ПРОВЕРИТЬ В ВАШЕЙ 1С
При ваших данных: первая строка 4 кг, вторая штатная масса 4 кг,
общая передаваемая масса 8 кг; цены 580/240 и сумма 4720 руб. прежние.
Проверьте также документ только в шт, кг с дробным количеством,
упаковки с коэффициентом и документ на несколько страниц.

ОГРАНИЧЕНИЯ
Новый прежний файл torg12_weights.mxl с параметрами МассаНетто и
КоличествоШтук с этой вставкой использовать нельзя: его новым именам
по-прежнему нужно заполнение в модуле обработки ПечатьТОРГ12.
Количество мест (14 в вашем примере) эта вставка не исправляет:
для этого нужны данные лотков/упаковок и код самой ПечатьТОРГ12.
В текущей среде нет платформы 1С: выполнение и внешний вид в ней
нужно проверить после установки. Сам модуль обработки ПечатьТОРГ12
не предоставлен; нижний подвал и итог страницы в его реализации
проверить здесь невозможно.
